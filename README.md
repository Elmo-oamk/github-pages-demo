# Cloud Services — Oppimispäiväkirja

Tämä sivusto on tehty osana Cloud Services -kurssia OAMK:ssa.

## Kurssilla opittua

Kurssilla käytiin läpi useita pilvipalveluihin liittyviä aiheita:

- **Docker** — konttiteknologia sovellusten paketoinnissa
- **Kubernetes** — konttien orkestrointi ja hallinta
- **CI/CD** — automaattinen rakennus- ja julkaisupipeline
- **Github Actions** — automaatio suoraan Github-repositorystä

## Tehdyt projektit

### 3-tier Docker-sovellus
Rakensin kolmikerroksisen sovelluksen:
1. Frontend — Nginx-webpalvelin
2. Backend — Python Flask -sovellus
3. Database — MySQL-tietokanta

### Kubernetes
Ajoin Kubernetes Basics -tutoriaalit Minikubella:
- Klusterin luonti
- Sovellusten deployaaminen
- Skaalaus ja päivitys

### Github Actions
Automatisoin Docker-kuvien buildauksen ja pushauksen Docker Hubiin.

## Teknologiat

| Teknologia | Käyttötarkoitus |
|---|---|
| Docker | Kontitus |
| Kubernetes | Orkestrointi |
| Github Actions | CI/CD |
| CSS Pouta | Linux VM |
| Python Flask | Backend |
| Nginx | Frontend |
